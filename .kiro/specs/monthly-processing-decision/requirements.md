# 月次処理の実行基盤を決める：要件

## 背景

新しい業務アプリは、業務時間中ずっと使われます。ここに、月末に多数の対象をまとめて点検し、帳票を作る処理（月次処理）を追加します。月次処理はオンライン業務と負荷の形が違うため、どこで動かすかを決める必要があります。

## 要件

1. 月次処理は、想定する最大件数の合成データを4時間以内に処理する。キューでの待ち、再実行、結果の保存、確認の時間を含む。
2. 月次処理を動かしている間も、オンライン業務の応答を遅らせない。
3. 一部が失敗したときは、その部分だけを重複なく再実行できる。
4. 運用者は、実行の状態、進み具合、失敗した部分を確認できる。個人の値は表示しない。

## 決めること

- 次に技術検証する実行基盤を1つ選ぶ。候補は、標準の AWS Lambda、Amazon ECS のタスク、AWS Batch の3つ。

## 決めないこと

- 本番の最終構成、データベース、認証、全体のサービス分割
