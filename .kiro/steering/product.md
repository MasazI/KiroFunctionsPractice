# このプロジェクトの前提

- 新しい業務アプリを、ゼロから作るプロジェクトです。いまは技術検討の段階で、アプリのコードはまだありません。
- チームは Java の経験があります。フロントエンドのフレームワークを使った経験はありません。
- 業務時間中はオンライン業務が続きます。まとめて動かす処理（月次処理など）が、オンライン業務を遅らせてはいけません。
- 要件は `docs/requirements/` にあります。
- 技術の判断は ADR（設計判断の記録）として `docs/decisions/` に残し、Git で共有します。
- データは合成データだけを使います。実在の個人情報、顧客名、資格情報、AWS アカウント ID、社内の URL は書きません。
- AWS へのデプロイや、AWS のリソースの作成・変更はしません。
- 依頼に関係のないファイルは変えません。
- ファイルを変えるときは、ファイル編集の機能を使います。シェルのコマンドやスクリプトでファイルを書き換えません。
- `git commit` と `git push` は、人が指示したときだけ行います。
