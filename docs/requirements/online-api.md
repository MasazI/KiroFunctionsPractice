# 要件：オンライン API

## 背景

新しい業務アプリのオンライン API は Java で作ります。画面からの参照と入力を受け付け、データベースに接続します。

## 要件

1. 業務時間中は、ずっと応答できる。
2. 応答時間の目標を満たす（目標の数値は業務部門と決める）。
3. データベースへの接続数を、上限の内に収める。
4. チームの Java の経験を活かせる。

## 決めること

- 次に技術検証する実行基盤を1つ選ぶ。候補は、Amazon ECS（AWS Fargate）と AWS Lambda（SnapStart）の2つ。
- 記録先：`docs/decisions/0002-online-api-runtime.md`

## 決めないこと

- 本番の最終構成、Java のフレームワーク、データベース、認証
