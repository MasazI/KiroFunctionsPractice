# 要件：月次処理の見積もりツール

## 背景

ADR-0001 で、月次処理を次にどの実行基盤で技術検証するかを決めた。技術検証の前に、所要時間を机上で見積もり、4時間の期限に収まりそうかを確かめたい。

## 要件

1. `tools/MonthlyEstimate.java` の1ファイルで作る。外部のライブラリは使わず、Java 11 以上で `java tools/MonthlyEstimate.java` として動く。
2. 引数は順に、総件数、1チャンクの件数、1チャンクの処理秒数、同時に動かす数。
3. 全体の処理時間が4時間に収まるか、1チャンクの処理時間が標準の AWS Lambda の上限（15分）に収まるかを表示する。
4. 引数が正しくないときは、使い方を表示して0以外で終了する。

## 確かめ方

- Spec の task が終わると、Hook が `scripts/check-estimate.sh` を実行する。
