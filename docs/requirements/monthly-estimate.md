# 要件：月次処理の所要時間の試算ツール

## 背景

ADR-0001 で、月次処理を次にどの実行基盤で技術検証するかを決めた。技術検証の前に、所要時間を机上で試算し、4時間の期限に収まりそうかを確かめたい。

## 要件

1. `tools/MonthlyEstimate.java` の1ファイルで作る。外部のライブラリは使わず、Java 11 以上で `java tools/MonthlyEstimate.java` として動く。
2. 引数は順に、総件数、1チャンクの件数、1チャンクの処理秒数、同時に動かす数。どれも1以上の整数。
3. チャンクの数と、全体の処理時間を表示する。チャンクの数と回数（チャンクの数 ÷ 同時に動かす数）は切り上げる。
4. 全体の処理時間が4時間に収まるか、1チャンクの処理時間が標準の AWS Lambda の上限（15分）に収まるかを表示する。ちょうど4時間、ちょうど15分は「収まる」とする。
5. キューでの待ち、起動、再実行の時間は含まないことを表示する。
6. 引数が正しくないときは、使い方を表示して0以外で終了する。引数が正しければ、収まらない結果でも0で終了する。

## 確かめ方

- Kiro が `tools/` の Java ファイルを作ったり変えたりすると、Hook が Kiro に `scripts/check-estimate.sh` の実行を頼む。手で `./scripts/check-estimate.sh` を実行してもよい。
